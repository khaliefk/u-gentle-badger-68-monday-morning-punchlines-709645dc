[make.fun](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc)
"Monday Morning Punchlines" bounty.

## Run it

Python 3, standard library only, no network, nothing to install:

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt`.

## The joke

> Monday morning: my weekend's free trial expired, and adulthood
> auto-renewed at full price. No refund button.

108 characters, inside the 200-character limit.
